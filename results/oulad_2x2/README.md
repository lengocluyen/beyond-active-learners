# Reported aggregate results

These summaries use the submission-time OULAD features. Average-precision intervals were recomputed from saved predictions using the exact `1 - p_success` tie convention; models were not refitted during this postprocessing.

`fit_protocol_original.json` records the original fitted experiment. `protocol.json` is an identical copy for plotting compatibility. `postprocessing_manifest.json` records the subsequent numerical processing and artifact hashes; its directory labels have been made project-relative for publication. Individual predictions and checkpoints are not included. Canonical aggregate intervals and exploratory contrasts are in [`../summary/`](../summary/).
